# Waterfall Chart | Power BI

## Overview

This project implements a **Waterfall Chart in Microsoft Power BI** to analyze the components contributing to changes between an initial and final business value.

The visualization provides a structured approach to **variance and contribution analysis**, making it easier to identify which factors are driving increases or decreases in overall performance.

## Analytical Focus

* Positive and negative contribution analysis
* Variance decomposition
* Driver identification
* Starting-to-ending value analysis
* Category-level performance assessment
* Interactive business analysis

## Technical Stack

* **Microsoft Power BI**
* **DAX**
* **Data Modeling**
* **Data Visualization**
* **Business Intelligence**

## Business Applications

Waterfall analysis can be applied to:

* Revenue and profit bridge analysis
* Budget vs. actual analysis
* Cost variance analysis
* Sales performance analysis
* Financial reporting
* Operational performance monitoring

## Objective

The objective is to present business movements in a structured format, allowing users to understand **how individual factors influence the overall change in a key metric**.

## Key Outcome

The dashboard transforms aggregated performance figures into a **driver-level view of variance**, helping stakeholders identify the underlying contributors to business performance and focus analytical attention on the factors creating the largest impact.
